# 本地控制台 v2：插件定位预览 设计文档

- 日期：2026-08-29
- 状态：待用户评审
- 范围：蕾米埃尔 Codex 桌宠本地控制台（`console_server.py` + `silent_pet.py`）

## 目标

在本地控制台页面中提供一块“桌面预览区”，直观展示桌宠与已打开插件的相对位置，并允许用户拖动插件示例来调整其相对桌宠的真实位置（松手保存并应用一次）。

## 交互模型

- 预览区位于页面顶部，尺寸 600×600，代表以桌宠为中心 ±400px 的真实区域（800×800）。
- 桌宠图标固定于预览区正中央，尺寸约 150px（真实 200px × 0.75 比例），后续可调。
- 所有“已打开”的插件以缩略示例图显示在各自相对位置，按 0.75 比例缩放。
- 拖动示例只在预览区内移动（本地页面状态）；松手时保存并应用一次，不做实时流。
- 示例拖不出预览区（吸附边缘）；真实插件窗口仍做屏幕边缘兜底。
- 插件列表中每张卡片下方新增该插件的示例图。
- 预览区提供“重置位置”按钮，一键恢复插件默认位置。

## 数据与存储

`config.json` 新增字段：

```json
{
  "plugin_positions": {
    "deepseek-balance": {"x": 0, "y": 110}
  }
}
```

- `x`/`y` 为“插件窗口中心”相对“桌宠窗口中心”的像素偏移（y 向下为正）。示例中 `{0, 110}` 表示徽章中心在桌宠中心正下方 110px。
- 未配置的插件使用其默认位置（余额徽章默认“桌宠正下方、上缘间隔 6px”，中心偏移由代码按徽章高度计算）。
- 位置更新由控制台 POST 写入并即时应用一次。

## 页面结构

1. 顶部：桌面预览区（600×600），含桌宠图标 + 插件示例 + 重置位置按钮。
2. 中部：插件列表卡片（现有样式），每张卡片下方新增插件示例图。
3. 底部：保留“公开插件市场”入口占位。

## API（console_server.py）

- `GET /`：控制台页面（服务端渲染插件卡片 + 预览区）。
- `GET /api/plugins`：插件列表（含启用状态）。
- `POST /api/plugins/<id>/enable|disable`：启用/停用插件。
- `GET /api/positions`：各插件相对位置 JSON。
- `POST /api/positions/<id>`：body `{"x": .., "y": ..}`，保存并应用一次。
- `GET /api/pet`：桌宠 silent 首帧缩略 PNG（预览区中心图标）。
- `GET /api/preview/<id>`：插件当前渲染的缩略 PNG（余额徽章由 compose_badge 动态生成）。

## 桌宠端改动（silent_pet.py）

- `_place_balance`：优先使用 `plugin_positions["deepseek-balance"]` 的偏移；无则用默认（正下方 6px）；仍保留屏幕边缘兜底。
- 新增 `_apply_plugin_position(id, x, y)`：写配置 + 通过 `root.after` 移动对应插件窗口。
- `_open_console`/控制台回调中接入新 API 需要的 `positions` / `preview` / `pet` 数据。
- 余额徽章预览图：调用 `compose_badge.compose()` 输出 PNG（缓存，避免每次请求重渲染）。
- 桌宠图标：取 `素材/silent.gif` 第一帧缩略 PNG（缓存）。

## 错误处理

- 预览图生成失败：API 返回 404/占位图，页面显示“示例不可用”。
- 位置保存失败：返回 `{"ok": false}`，页面提示。
- 桌宠进程未运行/端口失效：页面顶部显示“连接断开”提示。

## 测试

- 启动桌宠后打开控制台：预览区显示桌宠 + 余额徽章示例。
- 拖动余额示例 → 松手 → 真实徽章移动到新相对位置（数值与配置一致）。
- 重置位置 → 徽章回到默认（正下方 6px）。
- 停用插件 → 预览区示例消失；重新启用 → 示例按保存的位置出现。
- 桌宠贴屏幕边缘拖动 → 徽章不出屏（兜底生效）。

## 不做的事（YAGNI）

- 不做实时拖动流（拖动中仅页面内移动）。
- 不做插件卸载/日志界面。
- 不做公开插件市场实现（仅保留入口占位）。
