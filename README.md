# 蕾米埃尔 Codex 桌宠

一只会实时反映 Codex 工作状态的桌面宠物，基于“桌宠公开版”全模型改造。
项目名“蕾米埃尔”取自桌宠的昵称。

## 运行

1. 用 Windows Python 运行 `silent_pet.py`，或先跑 `build_pet.bat` 打包出 `蕾米埃尔codex桌宠.exe`。
2. 依赖：`pillow`、`pynput`（PyInstaller 打包 exe 也需要）。
3. 单实例：重复启动会自动退出。

## 配置（通用化，无个人路径）

项目不写死任何个人路径，所有应用都在运行时自动探测安装位置：

- 右键菜单（微信 / Steam / WPS 等）：按“注册表卸载项 → 常见安装路径 → 显式路径”的
  顺序自动探测，找不到的项自动隐藏。
- 双击打开 Codex：自动从已安装应用列表探测 Codex 桌面应用；探测不到时回退到默认别名。
- 会话目录：默认 `~/.codex/sessions`，可用环境变量 `CODEX_HOME` / `CODEX_PET_SESSIONS` 修改。

如需自定义菜单应用，把 `config.example.json` 复制为 `config.json` 放在 exe（或脚本）
同目录，按需增删即可；每项字段：

| 字段 | 说明 |
| --- | --- |
| name | 菜单显示名 |
| match | 注册表卸载项 DisplayName 匹配关键字（可多个） |
| exe | 可执行文件名，用于拼接安装目录 |
| paths | 常见安装路径（支持 `*` 通配符） |
| path | 显式路径（存在则优先使用） |
| icon | 菜单图标 PNG 文件名（可省略，省略时用首字兜底图标） |

`launch_apps` 配置存在时会**完全替代**默认列表；也可用环境变量 `CODEX_PET_CONFIG`
指定配置文件位置。`config.json` 已被 .gitignore 排除，不会进仓库。

## 状态说明

| 状态 | 触发时机 |
| --- | --- |
| silent | 默认待机循环 |
| think | 任意会话开始一轮任务（思考中），循环播放 |
| happy | 任意会话完成一轮任务，弹出并保持 3 秒；期间单击可提前收回，结束后若仍有会话在思考则回 think，否则回 silent |
| afterclick | 单击反馈动画（播一次） |
| work | 键盘 2 秒内连击 8 次唤醒 |

## 气泡

Codex 完成思考后，宠物上方会弹出**微信风格白色圆角气泡**（粉色不透明），
显示“爱思考先生/小姐，你的任务已经完成了~”。单击气泡或宠物即收回，**不打开任何窗口**。
气泡默认保持 3 秒自动收起（期间单击可提前收回）；多条会话并行时，只要还有会话在思考，
气泡收起后宠物会回到 think 状态。气泡会跟随宠物拖拽移动。

## 审批窗口

Codex 征求权限（需要升级执行命令）时，宠物会弹出同风格的**粉色不透明审批窗口**，
只显示授权原因（不展示命令代码行），可直接点击：

- 允许：点回 Codex 应用里的 Allow
- 总是允许：点回 Always allow
- 拒绝：点回 Deny

点击后桌宠通过 Windows UI 自动化把决定点回 Codex 应用的审批卡片（按钮文字中英文都匹配）。
应用卡片未渲染时会自动重试；右键点审批窗口可临时关掉（不做任何决定）。
命令被批准/拒绝后（会话日志出现对应结果），窗口会自动关闭。

“Approve for me（自动审批）”模式下：升级命令出现后先观察 3 秒，若 Codex 已自动批准
（日志出现执行结果）则不弹审批窗；观察窗过后还会用 UI 自动化探测 Codex 应用里
是否真的出现了审批卡片（有卡片才弹窗）。自动批准但执行较慢的命令不会误弹。
桌宠启动时不会重放历史未决审批。

## 交互

- 左键单击：收回气泡（happy 时）/ 播放单击动画（其余状态）
- 左键双击：收起气泡与菜单，并打开 Codex（未运行则启动应用）
- 审批窗口内：允许 / 总是允许 / 拒绝 三个按钮
- 按住拖拽：移动宠物，气泡跟随
- 右键单击：快捷菜单（微信 / Steam / WPS）
- 右下角缩放把手：按住拖动即可实时调整桌宠大小（120~400px）
- 右键双击：退出桌宠
- 键盘连击 8 次：work 动画
- 思考中（think）状态锁定：键盘连击、单击等不会切换到其它状态，直到思考完成才转 happy

## Codex 状态检测原理

后台线程轮询 `~/.codex/sessions` 下的 `rollout-*.jsonl` 会话日志（支持多线并行）。
只跟踪**真实用户任务**，忽略 Codex 内部自动审批评估线程（guardian，`thread_source=subagent`）：

- 任意会话 `task_started` / `user_message` → think（思考中）
- 任意会话 `agent_message(phase=final_answer)` / `task_complete` → happy + 气泡（3 秒）
- `function_call` 带 `sandbox_permissions=require_escalated` → 审批窗口
  （先观察 3 秒 + 探测应用里是否有审批卡片，确认需人工授权才弹；
   直到对应的 `function_call_output` 出现才视为已处理）

思考中判定：会话处于 busy 且日志文件 **5 分钟内有新写入**才算思考中；
中断/漏写完成标记的陈旧会话会自动失效，避免“全部完成仍卡 think”。

限制：只能感知写入本机 `~/.codex` 的会话（Codex 桌面版与 Windows 命令行版）；
WSL 里跑的 Codex 会话看不到。可用环境变量 `CODEX_PET_SESSIONS` 指向其它会话目录。

## 自定义

- 换动画：直接替换 `素材/` 下同名 GIF，重启生效。
- 换菜单：编辑 `config.json`（推荐），或 `silent_pet.py` 顶部的 `DEFAULT_LAUNCH_APPS`。
- 气泡样式：编辑 `silent_pet.py` 顶部 `BUBBLE_*` 常量（颜色、透明度、文案）。

## 与公开版的区别

- 去掉“单击打开对话窗 + API 配置”整套功能；
- `happy` 由“播一次”改为“保持 5 秒，单击可提前收回”；
- `think` / `happy` 改由 Codex 会话状态驱动，支持多会话并行；
- 新增微信风格气泡与“单击收回”交互；
- 新增审批窗口：Codex 征求权限时弹出，可直接允许 / 总是允许 / 拒绝。
